# Algoritmos y Estructuras de Datos

Este repositorio es un libro ligero para refrescar conceptos fundamentales antes de entrevistas técnicas. Cada capítulo se enfoca en una sola idea, la demuestra con Python y cierra con puntos de control listos para entrevistas.

## Cómo usar esta guía
- **Calienta** con la Parte 01 para reconstruir la intuición antes de sumergirte en los ejercicios de problemas.
- **Consulta** los capítulos de estructuras de datos y el apéndice cuando necesites un recordatorio rápido durante la práctica.
- **Toma notas** dentro de cada capítulo: trata esto como un cuaderno de trabajo vivo adaptado a tu estilo de aprendizaje.
